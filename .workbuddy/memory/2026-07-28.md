# 2026-07-28 工作日志

## SpecProt 任务文件夹 + 批量引擎 + 多端管理落地

### 完成事项
1. **`src/core/task-manager.ts`** — 任务文件夹引擎
   - 任务 = 独立功能模块的完整工作区
   - 结构: `{任务名}/00-素材/ → {web,h5,miniapp}/ → _shared/ → 产出/`
   - 7 种状态: 素材收集→批量生成→待精修→评审中→已冻结→已交付→暂缓
   - `collectMaterials()` 聚合素材上下文

2. **`src/core/batch-engine.ts`** — 批量处理引擎
   - 扫描所有任务，逐个生成/检查
   - 素材上下文自动注入到各端初稿
   - `BatchReport` 汇总到 `.speccore/batch-report.md`

3. **新增命令**：
   - `specprot task create/list/show/status`
   - `specprot batch --action generate/check/both`

4. **测试验证全流程**：
   - `task create --name "01-用户登录" --platforms web,h5,miniapp` ✅
   - 扔入 2 个素材文件，`batch --action generate` ✅
   - 三端初稿各含素材上下文，状态更新为"待精修"

### 架构决策
- 任务文件夹是独立的模块单元，不依赖全局层和期次层
- 批量引擎是"素材→生成→报告"的管道，适合下班前执行、上班后审阅
- 多端文档各自独立，`_shared/` 存放跨端共享的数据模型和业务规则

### 和用户的讨论要点
- 产品经理真实场景：分端写文档、模块独立任务、素材扔文件夹、批量执行
- 支持"晚上批量跑、白天精修"的异步工作流
- 需要把意图识别中的 task/batch 相关触发词补充进去
